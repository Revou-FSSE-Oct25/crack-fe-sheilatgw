# 📖 About The Project

Uno is a web-based application developed as part of the RevoU Full Stack Software Engineering program. The application is designed with a responsive interface, reusable component architecture, and modern frontend development practices to provide a seamless user experience across devices.

The project emphasizes:

- Responsive UI/UX
- Reusable components
- Client-side routing
- API integration
- Clean code structure
- Scalable frontend architecture
